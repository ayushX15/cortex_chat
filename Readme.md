### Cortex Chat

Cortex Chat is an advanced interactive chatbot project built using the LLaMA 2 large language model.  
It is designed to provide natural, human-like conversations through a clean and modern web interface.

## 🚀 Features

- 🤖 Chatbot powered by LLaMA 2 (Meta's large language model)
- 🌐 Modern, responsive web UI
- 💬 Handles context for smooth multi-turn conversations
- 🔧 Easy to configure and extend

## 🛠️ Tech Stack

- 🧠 **Backend:** Python (FastAPI / Flask) serving LLaMA 2 model
- 💻 **Frontend:** HTML, CSS, JavaScript (optional enhancements with React)
- 📦 **Dependencies:** transformers, torch, llama-cpp, flask / fastapi


## 🚀 Future Improvements

- Add user authentication
- Save chat history to database
- Deploy on cloud with GPU (AWS / GCP)
- Add speech-to-text / text-to-speech
